# skills

Small, agent-agnostic [Agent Skills](https://agentskills.io) I use myself. Each one is short enough to read in a minute, and I've read every line.

## Install

```sh
npx skills add shostakovich/skills
```

Or copy a `skills/<name>` folder into your agent's skills directory.
